# Guidelines Data Convention

- Keep guideline content split by school, year, and source section.
- Do not grow one guidelines data file into a large monolith; add a new section file under `data/<school><year>/`.
- Keep each source file comfortably below 1,000 lines.
- Store English and Arabic text together in the same topic so search, filters, and source links stay aligned.
- Summaries must be rewritten and clinically faithful; do not paste long source passages verbatim.
