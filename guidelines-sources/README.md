# Guidelines Source Files

ضع ملفات الجايدلاينز الأصلية هنا حتى أقدر أرجع لها عند التلخيص أو بناء شات الجايدلاينز.

## البنية المقترحة

- `guidelines-sources/_inbox/`
  - ضع هنا أي ملفات جديدة بسرعة لو لسه مش متأكد من المدرسة أو السنة.
- `guidelines-sources/ADA/2026/`
  - ملفات ADA 2026 عند إضافتها.
- `guidelines-sources/AACE/`
  - ملفات AACE حسب السنة.
- `guidelines-sources/ESC/`
  - ملفات ESC حسب السنة.
- `guidelines-sources/EASD/`
  - ملفات EASD حسب السنة.

## تسمية الملفات

استخدم ترقيم واضح قدر الإمكان:

- `01 Improving Care and Promoting Health in Populations.pdf`
- `02 Diagnosis and Classification of Diabetes.pdf`
- `03 Prevention or Delay of Diabetes.pdf`

## ملاحظة مهمة

ملفات PDF الأصلية متجاهلة من Git عمدا حتى لا يكبر حجم المشروع. وجودها محلي فقط يكفي للقراءة والتلخيص وبناء الفهرسة لاحقا.
